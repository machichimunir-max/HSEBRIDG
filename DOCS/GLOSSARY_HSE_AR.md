# Glossaire HSE — Français / العربية

Ce glossaire regroupe les termes HSE utilisés dans la plateforme HSE BRIDGE. Les traductions ont été choisies pour leur usage professionnel dans le domaine de la Santé, Sécurité et Environnement au Maroc et au Maghreb.

| Terme Français | الترجمة العربية | Contexte / Notes |
|---|---|---|
| **Métiers HSE / المهن** |||
| Animateur HSE | منشط السلامة والصحة والبيئة | Personne qui anime les sessions de sensibilisation HSE |
| Supervisor HSE | مشرف السلامة والصحة والبيئة | Responsable de la surveillance sur le terrain |
| Inspecteur HSE | مفتش السلامة والصحة والبيئة | Effectue les inspections de conformité |
| Responsable HSE | مسؤول السلامة والصحة والبيئة | Chef du département HSE |
| Supervisor Levage | مشرف عمليات الرفع | Spécialiste des opérations de levage |
| Technicien travail en hauteur | تقني العمل في المرتفعات | Expert en travaux en hauteur |
| Technicien espace confiné | تقني الأماكن المغلقة | Spécialiste des espaces confinés |
| SST (Sauveteur Secouriste du Travail) | مسعف في العمل | Premiers secours en entreprise |
| **Formation / التكوين** |||
| Formation | تكوين | Processus d'apprentissage |
| Formation certifiante | تكوين معتمد | Formation avec certification officielle |
| Attestation | شهادة | Document officialisant une formation |
| Module | وحدة | Unité d'enseignement |
| Leçon | درس | Contenu pédagogique |
| Apprenant / Étudiant | طالب / متعلم | Personne suivant une formation |
| Inscription | تسجيل | Processus d'enrôlement |
| Progression | تقدم | Avancement dans un cursus |
| Évaluation | تقييم | Test de connaissances |
| Quiz | اختبار | Questionnaire à choix multiples |
| Certificat | شهادة | Document officiel de réussite |
| Programme | برنامج | Ensemble de modules de formation |
| **Sécurité / السلامة** |||
| Sécurité au travail | السلامة في العمل | Protection des travailleurs |
| Santé, Sécurité, Environnement | الصحة والسلامة والبيئة | Domaine HSE complet |
| Accident du travail | حادث عمل | Accident survenu au travail |
| Incident | حادثة | Événement non souhaité sans gravité majeure |
| Risque | خطر / مخاطرة | Combinaison probabilité/gravité |
| Danger | خطر | Source potentielle de dommage |
| Mesure préventive | إجراء وقائي | Action pour réduire les risques |
| Plan d'urgence | خطة الطوارئ | Procédure de réponse aux situations critiques |
| Analyse des risques | تحليل المخاطر | Identification et évaluation des risques |
| Audit | تدقيق | Examen systématique de conformité |
| Inspection | تفتيش | Vérification sur le terrain |
| Conformité | مطابقة | Respect des normes et réglementations |
| Norme | معيار | Standard de référence |
| ISO 45001 | ISO 45001 (المعيار الدولي لنظام إدارة السلامة) | Norme internationale de management de la SST |
| ISO 14001 | ISO 14001 (المعيار الدولي للإدارة البيئية) | Norme internationale de management environnemental |
| **Équipements de Protection / معدات الوقاية** |||
| Équipement de Protection Individuelle (EPI) | معدات الوقاية الفردية | Protection individuelle du travailleur |
| Équipement de Protection Collective (EPC) | معدات الوقاية الجماعية | Protection pour un groupe de travailleurs |
| Casque de sécurité | خوذة السلامة | Protection de la tête |
| Lunettes de protection | نظارات الحماية | Protection des yeux |
| Protection auditive | حماية السمع | Bouchons ou casques antibruit |
| Gants de sécurité | قفازات السلامة | Protection des mains |
| Chaussures de sécurité | أحذية السلامة | Protection des pieds avec embout |
| Gilet haute visibilité | سترة عاكسة | Vêtement rétroréfléchissant |
| Harnais de sécurité | حزام الأمان | Pour travail en hauteur |
| Masque respiratoire | قناع تنفسي | Protection respiratoire |
| Protection de la tête | حماية الرأس | Casque, casquette de sécurité |
| Protection des yeux | حماية العينين | Lunettes, écrans faciaux |
| Protection des mains | حماية اليدين | Gants adaptés aux risques |
| Protection des pieds | حماية القدمين | Chaussures et bottes de sécurité |
| Vêtements haute visibilité | ملابس الرؤية العالية | Pour travaux en circulation |
| **Domaines spécialisés / التخصصات** |||
| Travail en hauteur | العمل في المرتفعات | Travaux au-dessus de 2 mètres |
| Espace confiné | الأماكن المغلقة | Espace clos à accès limité |
| Lutte contre l'incendie | مكافحة الحرائق | Prévention et intervention incendie |

| Levage | الرفع | Opérations de levage de charges |
| Appareils de levage | معدات الرفع | Grues, palans, élingues |
| Signalisation | لوحات الإشارات | Panneaux et consignes |
| Balisage | علامات التحذير | Marquage des zones dangereuses |
| **Recrutement / التوظيف** |||
| Recrutement | توظيف | Processus d'embauche |

| Candidature | طلب توظيف | Dossier de candidature |
| Offre d'emploi | عرض عمل | Annonce de poste à pourvoir |
| Intérim | عمل مؤقت | Emploi temporaire |
| CDD | عقد محدد المدة | Contrat à Durée Déterminée |
| CDI | عقد غير محدد المدة | Contrat à Durée Indéterminée |
| Mission | مهمة | Affectation temporaire |
| Compétence | كفاءة | Savoir-faire requis |

| Boutique | متجر | Catalogue de produits |
| Devis | عرض أسعار | Estimation tarifaire |
